# Illustrations

`whale-forge.jpg` is the README hero: a whale blacksmith resting at the forge,
tea in one hand. Operator-provided and AI-generated (2026-10); it is decorative,
not a screenshot of the product.

The stored copy is 1600 px wide (196 KB), downscaled from the 2741 px original
so the repo and the npm tarball stay small; it is displayed at 860 px in
[`../../README.md`](../../README.md). Do not replace it with a larger file
without downscaling again (see "Docs and translations" in
[`../../devops/workflow.md`](../../devops/workflow.md)).
